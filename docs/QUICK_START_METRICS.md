## 🎁 BONUS

### Statistiques Scientifiques

```
μ (mu)     = Moyenne
σ (sigma)  = Écart-type
           = √(Σ(xi-μ)²/n)

CV = σ/μ × 100%
   = Coefficient de variation

Interprétation:
CV < 15%   → Excellent ! Résultats consistants
CV < 30%   → Bon
CV > 50%   → Variable
```
