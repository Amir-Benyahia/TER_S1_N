# Présentation TER S1 — Pacman Maze Platform

Ce dossier contient la version du 14 novembre 2025 de la présentation destinée au jury.  
Le support principal est `presentation.html`, une présentation moderne 100% HTML/CSS/JS exploitant un mode plein écran avec navigation clavier.

## Comment lancer

1. Ouvrir `presentation.html` dans un navigateur Chromium ou Firefox à jour.  
2. Passer en plein écran (`F11`) puis utiliser :
   - Boutons « Précédent/Suivant »
   - Flèches gauche/droite du clavier
3. Chaque membre dispose d’un bloc ≤ 4 min (cf. plan ci-dessous).
