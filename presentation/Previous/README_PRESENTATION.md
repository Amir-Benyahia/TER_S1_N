## 🆘 Plan B - Si Problème Technique

### Problème 1: Projecteur ne fonctionne pas
**Solutions:**
1. Utiliser l'ordinateur de la salle
2. Présenter sur votre écran (si petit groupe)
3. Imprimer les slides principales (backup papier)
4. Improviser en suivant AIDE_MEMOIRE

### Problème 2: presentation.html ne s'ouvre pas
**Solutions:**
1. Ouvrir presentation_slides.md dans un éditeur de texte
2. Lire directement depuis le Markdown
3. Utiliser AIDE_MEMOIRE comme support
4. Improviser avec vos RA

### Problème 3: Ordinateur crash
**Solutions:**
1. Utiliser l'ordinateur d'un coéquipier
2. Utiliser l'ordinateur de la salle
3. Présenter sans support visuel (vous connaissez votre sujet!)
4. Reporter de quelques minutes le temps de redémarrer

### Problème 4: Site web inaccessible (pour démo)
**Solutions:**
1. Expliquer: "Le site est en veille (free tier)"
2. Montrer le code dans src/ à la place
3. Montrer des screenshots (si préparés)
4. Passer directement aux questions

### Problème 5: Vous perdez votre fil
**Solutions:**
1. Regarder la slide actuelle (ça va vous rappeler)
2. Dire: "Comme vous pouvez le voir ici..."
3. Consulter discrètement AIDE_MEMOIRE sur téléphone
4. Passer la parole: "Vous voulez ajouter quelque chose?"

## ❓ Questions Fréquentes

### "Quel fichier utiliser pour présenter ?"
→ **presentation.html** (recommandé) car prêt à l'emploi, design moderne, navigation facile.

### "Dois-je mémoriser tout le texte ?"
→ **Non !** Comprenez les concepts, regardez les slides pour vous guider. L'essentiel est dans AIDE_MEMOIRE.

### "Combien de temps doit durer ma partie ?"
→ **Maximum 4 minutes** par personne. Utilisez un chronomètre pour vous entraîner.

### "Dois-je faire une démonstration live ?"
→ **Optionnel.** Si le temps le permet (et connexion stable), ça fait toujours effet. Sinon, les slides suffisent.

### "Que faire si on me pose une question difficile ?"
→ Pas de panique ! Dites: "Bonne question, nous n'avons pas encore exploré cet aspect" ou "Je peux vous montrer le code après".

### "Comment gérer le stress ?"
→ 
1. Respirer profondément avant de commencer
2. Sourire (ça détend)
3. Regarder l'audience (pas le mur)
4. Se rappeler: vous connaissez votre sujet !
5. Boire de l'eau

### "Puis-je modifier les slides ?"
→ **Oui !** Éditez presentation.html ou presentation_slides.md. Mais attention aux modifications de dernière minute.

### "Où trouver plus d'informations sur mon travail ?"
→ Dans votre rapport d'activité: `RA/ra_VotreNom.md`
